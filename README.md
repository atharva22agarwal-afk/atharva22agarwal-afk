## ◈ Featured Projects

<details>
<summary><b>⬡ &nbsp; NewsMind.AI — AI-Powered News Intelligence Platform</b></summary>

<br/>

A real-time AI news analysis platform that uses a **hybrid LLM architecture** combining Llama and Gemini models to deliver forensic-grade media intelligence. The system performs bias detection by analysing omission patterns, entropy, and content density across multiple news sources simultaneously, and features a live AI debate engine where opposing viewpoints are scored in real time.

| Attribute | Detail |
|---|---|
| **Stack** | Node.js · Express.js · PostgreSQL · Socket.io · Llama · Gemini API · React.js |
| **Scale** | Real-time multi-source aggregation · live WebSocket debate sessions |
| **Performance** | Hybrid LLM routing for latency-cost optimisation · real-time scoring |
| **Security** | API key management · rate-limited endpoints · validated inputs |
| **Impact** | Forensic bias detection across news sources · live AI-moderated debate engine |
| **Repository** | [![GitHub](https://img.shields.io/badge/View%20Repo-6D28D9?style=flat-square&logo=github&logoColor=white)](https://github.com/atharva22agarwal-afk) |

NewsMind.AI implements a news ingestion pipeline that pulls from multiple sources, normalises content, and passes articles through a bias scoring engine that evaluates omission (what is not said), entropy (diversity of perspectives), and content density (depth vs. sensationalism). The live debate engine uses Socket.io to stream real-time arguments generated by LLMs taking opposing positions, scored for logical coherence and evidence quality. The entire backend is built on Node.js, Express.js, and PostgreSQL with scalable API design.

<br/>
</details>

<details>
<summary><b>⬡ &nbsp; Lumina — AI-Powered Personal Wellness Dashboard</b></summary>

<br/>

A comprehensive personal wellness platform that combines affirmations, AI-guided meditation, journaling, focus timers, mood tracking, and vision boards into a single, beautifully designed application. Powered by the **Groq AI API** for ultra-fast, personalised meditation script generation with offline fallback support.

| Attribute | Detail |
|---|---|
| **Stack** | React.js · Framer Motion · Groq AI API · localStorage · Tailwind CSS |
| **Scale** | Full client-side app · persistent data across sessions via localStorage |
| **Performance** | Groq-powered sub-second AI generation · smooth 60fps Framer Motion animations |
| **Security** | Client-side data isolation · no sensitive data transmitted |
| **Impact** | End-to-end wellness UX: mood tracking · journaling · AI meditation · vision boards |
| **Repository** | [![GitHub](https://img.shields.io/badge/View%20Repo-6D28D9?style=flat-square&logo=github&logoColor=white)](https://github.com/atharva22agarwal-afk) |

Lumina is built with a component-first React architecture using Framer Motion for all page transitions and interactive UI elements. The Groq AI integration generates personalised meditation scripts tailored to the user's current mood and session history, with a graceful offline fallback library. Data persistence is handled entirely through browser localStorage across affirmations, mood history, journal entries, and vision boards. The UI follows a calming, spiritual aesthetic using Playfair Display typography and glassmorphism card effects for a premium, intentional experience.
